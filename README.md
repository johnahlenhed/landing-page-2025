# 3D Product Showcase Website

A modern e-commerce website with interactive 3D product visualizations built with Three.js, PHP, and vanilla JavaScript. The site showcases furniture and audio products with customizable materials and an exploding view feature for detailed product exploration.

## Features

### Interactive 3D Models

- **Chair Customizer**: Real-time material and texture swapping for chair components
- **Speaker Exploding View**: Interactive slider-controlled exploded view of a speaker with smooth camera animations
- **Orbit Controls**: Intuitive 3D navigation with zoom, pan, and rotate capabilities

### Responsive Design

- Mobile hamburger menu with smooth transitions
- Desktop navigation bar
- Touch-friendly interface elements

## Technologies Used

### Frontend

- **Three.js** - 3D graphics rendering
  - OrbitControls
  - GLTFLoader
  - OBJLoader
  - HDRLoader
  - Post-processing effects (FXAA)
- **Vanilla JavaScript** - Interactive UI components
- **CSS3** - Modern styling with custom properties

### Backend

- **PHP** - Server-side rendering and includes

### 3D Assets

- **GLTF/GLB Models** - Optimized 3D speaker model
- **OBJ Models** - Chair model with UV mapping
- **HDR Textures** - Environment maps for realistic lighting
- **PBR Texture Maps** - Multiple material texture sets
